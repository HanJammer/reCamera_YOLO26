reCamera ONNX → CVI Model Converter

Upload a YOLO detection ONNX and a test image. The tool derives YOLO11/YOLO26 output names, runs TPU-MLIR in Docker, and returns a reCamera-ready .cvimodel + model.json.

v1 scope: detection models only, CV181x target, F16 precision. Segmentation/pose/classification are not supported yet.
Backend: {{ docker_hint }} Uses sophgo/tpuc_dev:v3.1.

What you get

  • *_cv181x_f16.cvimodel
  • model.json with class names
  • output_names.txt
  • commands.sh and conversion log
  • ZIP bundle for download
